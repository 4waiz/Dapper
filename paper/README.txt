DAPPER - FMEC 2026 camera-ready LaTeX source (revised)

Build
  pdflatex DAPPER_FMEC2026_CameraReady.tex   (run twice)
  or: latexmk -pdf DAPPER_FMEC2026_CameraReady.tex
Paper size A4, IEEEtran conference class, 7 pages.

Figures
  dapper_architecture.pdf              generated by experiments/make_architecture_figure.py
  fig2_p95_latency_panel.pdf           generated by experiments/make_figures.py
  fig2b_usable_confidence_panel.pdf    generated by experiments/make_figures.py
  fig3_deadline_mode_distribution.pdf  generated by experiments/make_figures.py
  runtime_bias.pdf                     sensitivity panel

Provenance
  Every number in the paper is generated from a CSV under results/ in
  https://github.com/4waiz/Dapper and was re-verified against those CSVs
  (407 numeric claims checked programmatically).
  Table bodies can be regenerated with:
      python experiments/make_paper_latex_tables.py
