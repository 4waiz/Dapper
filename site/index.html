    Deadline-aware edge perception · IEEE FMEC 2026

    watch it decide

    An answer after the deadline isn't a late answer. It's no answer.

    Mission-critical robots have milliseconds. A stronger model on the edge is worth having, but it puts the network in the critical path, and the right place to run a frame changes frame by frame. DAPPER scores each frame's deadline risk, places it, and refuses any remote result that arrives outside its freshness window.

          Policy race

          Five policies, one immutable future.

          Each replays the identical trace through the identical cost model, so a decision selects which outcome is realised but cannot change the random future. The oracle reads the realised outcome of the current frame and is not deployable; it is here to bound what perfect knowledge of the next instant would buy.
